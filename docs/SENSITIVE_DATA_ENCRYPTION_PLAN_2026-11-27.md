# 로그인 정보·법인카드 암호화 계획 (미구현)

2026-11-27. 점검 5단계의 5번 항목 중 **백업에서 기본 제외**만 구현했고(결정), 암호화는 이 문서로만 남긴다.
저장 형식은 바꾸지 않았다.

남는 위험: 이 PC의 Windows 계정에 접근할 수 있는 사람이나 프로그램은 브라우저 저장소를 읽을 수 있다.

## 구현한다면

- 대상: 비밀번호 칸(`password`)과 법인카드의 카드 번호가 들어간 칸. 사이트 이름·아이디는 검색이 필요해 그대로 둔다.
- 방법: 로그인 비밀번호와 **별도의 보관함 암호** → PBKDF2(SHA-256, 60만 회 이상) → AES-GCM. 칸 값은
  `{ "enc": 1, "iv": "...", "data": "..." }`, 소금(salt)과 반복 횟수는 같은 DB의 설정 한 건.
- 암호와 키는 저장하지 않는다. 화면에서 보관함을 열면 메모리에만 두고, 일정 시간 뒤 잠근다.
- WebCrypto는 `localhost`와 HTTPS에서만 동작한다 — 다른 PC에서 HTTP로 접속하면 열 수 없다.
- 복구 키: 처음 설정할 때 한 번 보여 주고 종이로 보관하게 한다. **암호와 복구 키를 모두 잃으면 되살릴 수 없다.**

## 순서와 되돌리기

1. [RND 업무]를 켠 백업을 내려받아 [저장한 파일 확인]까지 한다(되돌릴 사본).
2. 암호화 값을 읽고 쓰는 코드를 먼저 배포한다. 평문 값도 계속 읽는다.
3. 설정 화면에서 암호를 정하면 한 건씩 암호화하고, 다시 풀어 원래 값과 같은지 확인한 뒤 평문을 지운다.
4. 중간에 멈춰도 평문·암호문이 섞인 상태를 그대로 읽을 수 있어야 한다.
5. 되돌리기: 보관함을 연 상태에서 [평문으로 되돌리기], 또는 1의 백업을 복원한다.
