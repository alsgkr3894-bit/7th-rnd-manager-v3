# 원가 흐름 전체 점검 결과 — 2026-10-30

범위: 제때 단가 업로드 → 식자재 관리 → 메뉴마스터 → 원가 계산 → 원가 출력(웹·PDF·엑셀) + 보안.
방법: 실데이터(로컬 Postgres, 읽기 전용) 기준선 + 코드 점검 + 회귀 테스트. 데이터는 하나도 바꾸지 않았다.

재실행: `npm run audit:recipe-cost`(기존, 4곳 비교) · `node scripts/audit-cost-pipeline.mjs`(신규, 7곳 비교 + 단가 건강검진 + 판매가 이원화 + 반올림 오차).

## 1. 실데이터 기준선 (최신 단가파일 2026-10-20, 109행)

| 점검 | 결과 |
|---|---|
| 메뉴마스터·원가마진표·원가계산보고서·레시피출력·전체요약·토핑 | **72개 메뉴 전부 같은 원가** (불일치 0) |
| 홈(원가율 계산) | 72개 중 34개 메뉴가 **999~4,041원 낮음(평균 2,317원)** — 전부 공통묶음 구성품이 있는 메뉴. 홈은 직접 구성품만 계산하는 것이 의도된 동작(메모리: 홈/마진표 경보 수 차이). → 결정 사항 |
| 판매가 이원화 (메뉴마스터 price ↔ 원가 쪽 판매가) | 불일치 0, 원가 쪽에만 남은 행 0 |
| 조용한 0원 줄 (단가·수량 없어 원가에 0으로 들어간 구성품) | 판매 중 메뉴 0개 |
| 레시피 줄 단위 ↔ 식자재 단위 불일치 | 0건 |
| 단가파일 코드 대소문자 불일치 | 0건 |
| 단가가 없는데 레시피에서 쓰는 식자재 | 0건 |
| 단가파일에 없는 코드가 있는 식자재 | 11개 (레시피 사용 중인 것은 CC410251 고르곤졸라치즈 1개 — 수동 단가 5,203원, 판매가 없는 고르곤졸라 피자에만 쓰임) |
| 포장수량 0 이하 식자재 | 37개 (이름 없는 단가 연동 껍데기가 대부분, 레시피에서 쓰는 것 0개) |
| 단가 반올림(0.1원)이 메뉴 원가를 0.5원 이상 바꾼 메뉴 | 45개, **최대 10.2원(0.1%)** — 컨츄리치킨 피자 L 등. 양파 100g 4.7%(4.5원) |
| 판매가 없는데 레시피 있는 메뉴 | 6개: 고르곤졸라 피자 L·R·1인용, 석쇠, 시나몬츄러스 2PCS, 씬바사삭 |
| 코드 없는 레시피 구성품 | 93줄 (이름으로 식자재에 연결 — 현재 전부 단가가 잡힘) |
| 원가표 미연결 | 수제피클(레시피 원가 0) 1개 |

결론: **지금 데이터에서는 원가 화면 6곳이 같은 숫자를 낸다.** 아래 버그는 현재 값을 틀리게 만들고 있지는 않지만, 다음 업로드·입력에서 조용히 잘못된 값이 들어갈 수 있는 구멍이거나 출력 표시가 오해를 부르는 곳이다.

## 3. 결정이 필요한 것 (값이 달라지거나 정책이 얽혀 있어 고치지 않음)

| # | 내용 | 영향 | 제안 |
|---|---|---|---|
| D1 | 홈 원가율은 직접 구성품만(공통묶음·엣지·하프앤하프 제외) | 홈 평균 원가율이 마진표보다 낮게 보임(34개 메뉴, 평균 2,317원) | 홈도 공용 원가 함수로 통일할지 |
| D2 | 단가를 0.1원 단위로 반올림해서 곱함 | 메뉴당 최대 10원(0.1%), 양파 100g 같은 저가·소량은 4.7% | 단가는 반올림하지 않고 합계에서 한 번만 반올림하면 오차 0. 모든 화면 값이 1~10원 움직임 |
| D3 | 하프앤하프: 마진표는 반올림 안 함·원가보고서는 반올림 | 소수점 차이 | 규칙 하나로 |
| D4 | 숨김 메뉴: 마진표는 제외, 원가보고서·전체요약은 포함 | 보고서에 숨긴 메뉴가 나옴 | 포함 여부 통일 |
| D5 | 원가보고서에 소스·음료 카테고리가 없음(마진표엔 있음) | 보고서 범위 | 추가할지 |
| D6 | 경고선: `isCostRateOverThreshold`는 `>`, MarginRow 색은 `>=`, 홈은 소수 한 자리 반올림 후 비교 | 경계값(정확히 40.0%)에서만 다름 | `>` 하나로(기존 결정 `risk-threshold.js`) |
| D7 | 전체요약은 메뉴명으로만 묶음 — 규격이 다르면 원가와 판매가가 다른 규격일 수 있음 | 현재 데이터는 이름에 규격이 들어 있어 영향 없음 | 규격 단위로 묶기 |
