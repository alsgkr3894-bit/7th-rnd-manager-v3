# 영양성분 모듈 정밀 감사 — 2026-09-16

법적 표시(영양성분·알레르기·원산지)를 만드는 모듈이라 **값의 정확성**과 **타 모듈(메뉴마스터·식자재·레시피)
연동**을 코드 검토 + 실서버 데이터 전수 재계산 + 브라우저 실동작 세 겹으로 확인했다.

## 범례
| 표시 | 의미 |
|---|---|
| ✅ | 정상 확인 |
| ⚠️ | 동작하나 주의/데이터 보완 필요 |
| ❌ | 버그(수정함) |
| 🔴 | **데이터 누락 — 법적 표시에 영향, 사용자 입력 필요** |
| ⏭ | 미실행(사유 기재) |

## 환경
- 서버: 로컬 PostgreSQL `rnd_manager`, Next.js dev `http://localhost:3000`, 브라우저: 프리뷰 탭(운영 PC 모드, admin)
- 데이터: 서버에서 불러오기로 실데이터 적재(67,841행). 영양 스토어: `nutrition_menu_ref` 8, `nutrition_raw_values` 19,
  `nutrition_edge_master` 4, `nutrition_topping_master` 13(+1), `nutrition_set_composition` 2, `cost_edge_dough` **0**
- 재계산 스크립트: 스크래치 jest(`@/lib/db`를 서버 API 스냅샷 위 메모리 구현으로 대체, 쓰기 금지) →
  앱 빌더(`buildPizzaSheet`/`buildPizzaSliceSheet`/`buildSideSheet`/`buildToppingSheet`/`buildSetHalfSheet`/`buildBeverageSheet`)
  실행 후 독립 산술(100g값×150/100, 100g값×총중량×조각비율/100, 베이스+엣지 합산, 세트 min/max)과 셀 단위 대조
- 법적 기준(식약처): 조리·판매업소 어린이 기호식품 영양표시 의무 5종 = **열량·당류·단백질·포화지방·나트륨**, 알레르기 유발물질 22종.
  반올림은 "계산값 그대로 또는 5kcal/5·10mg 단위" 모두 허용 → 앱의 정수 반올림은 적법.

  [찾기쉬운 생활법령 — 어린이 기호식품 표시](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1113&ccfNo=2&cciNo=2&cnpClsNo=1),
  [식약처 알레르기 유발 식품 표시](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?menu_no=3120&menu_grp=MENU_NEW01&bbs_no=bbs001&ntctxt_no=1091412)

## §2. 연동 정합성

| 항목 | 결과 | 비고 |
|---|---|---|
| 영양 메뉴 ↔ 메뉴마스터 코드 | ❌→✅ | 영양 메뉴는 베이스 코드(`P-OR-006`), 마스터는 full 코드(`P-OR-006-L`) — 라벨 컨텍스트 조회 5/8 실패하던 것을 8/8로(§4-B4) |
| 영양 메뉴명 ↔ 마스터명 | ⚠️ | 4건 불일치: 영양 메뉴 "고르곤졸라 피자 L"(마스터 "고르곤졸라 피자"), "샘스테이크 피자"(마스터 "샘스테이크 피자 R/L"), 1인용 2건. 표에는 영양 메뉴명이 찍힘 — 표 출력의 "출력명·순서" 기능으로 교정 가능. 마스터명에 사이즈가 섞여 있어 자동 전파는 하지 않음(§5-2) |
| 단종 메뉴가 표에 포함되는지 | ✅ | 실데이터 8건 중 해당 없음. 사용자 결정에 따라 단종 자동 제외 구현(§5-3) |
| 크러스트 완결성 | 🔴 | `P-PS-001 샘스테이크` 석쇠L: **당류·포화지방 미입력** → 150g·조각 표 L열이 "—"(의무 표시 공백). 나머지 4메뉴는 3크러스트 모두 입력됨 |
| 알레르기 22종 목록 | ⚠️ | `ALLERGEN_SEED` 22개 = 법정 21종(굴·전복·홍합 개별) + **아몬드**(국내 법정 항목 아님). 화면 문구 "한국 법정 알레르기 22종"에 아몬드 포함 — 표시 자체는 허용되나 문구 수정 권고 |
| 알레르기 집계 사슬 | 🔴 | ① `cost_edge_dough` 0건 → **도우의 밀·대두가 피자 어디에도 반영 안 됨**(알레르기 페이지에서 도우(L)/(R) 매칭 메뉴 0). ② 1인용 피자 2개 레시피 없음 → 알레르기 "—". ③ 레시피 구성품 18종이 식자재 마스터에 없음(까망베르슈레드치즈 CC411436·피자소스 CC410249는 거의 모든 피자에 사용) → 우유·토마토 누락 가능. 현재 표: 고르곤졸라 "우유"만, 페페로니 "우유, 돼지고기, 쇠고기"(밀 없음). → §4-F 배너로 화면에 노출하도록 수정, 데이터 보완은 사용자 몫 |
| 원산지 표시판 | ⚠️ | `cost_ingredients.origin`·레시피 기반 정상 생성. 원산지 미등록 식자재 18개(화면 배너 있음). 코드 키 단일 대소문자 문제(S6)는 현재 코드가 전부 대문자라 실영향 없음 |
| 대시보드 지표 | ⚠️ | "영양성분 입력 8개·100%"는 영양 메뉴 8건 기준 — 메뉴마스터 86건 중 78건은 영양 메뉴 자체가 없어 집계 밖(§4-D3). "알레르기 커버리지 95%"도 위 누락을 반영하지 못함 |
| 중복 데이터 | ⚠️ | `nutrition_raw_values`에 `P-ONE-001 하와이안(1인용)`·1인용피자 2행(250g/50kcal vs 257g/305kcal). 영양 메뉴 목록에는 없어 표에는 안 나감. 화면의 "중복 정리" 버튼으로 정리 가능(⏭ 미실행 — 어느 행이 맞는지 판단 필요) |
