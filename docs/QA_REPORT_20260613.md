### 3-1. `lib/work-log.js:90` — `toISOString().slice(0, 10)`

```js
export function workLogCutoffDate(keepDays, now = new Date()) {
  const cutoff = new Date(now);
  cutoff.setDate(cutoff.getDate() - keepDays);
  return cutoff.toISOString().slice(0, 10); // UTC 기준
}
```

- **영향 없음**: 작업로그 정리 cutoff 날짜 — 사용자 입력 날짜가 아닌 내부 TTL 계산. 1일 오차가 발생해도 로그 보존/정리 정책에 영향 없음.
