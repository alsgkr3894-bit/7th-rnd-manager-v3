## High

### BUG-001 — 메뉴 마스터 편집 모달 저장 중복 (`components/menu-master/MenuMasterEditModal.jsx`)

- **증상**: `submit()`에 저장 진행 가드가 없어, 저장 중 `Ctrl+S`(`useKeyboardSave`) 연타 시 `onSave → upsertMenuMaster`가 여러 번 호출되어 동일/유사 레코드가 중복 삽입될 수 있음.
- **재현**: 편집 모달에서 코드·이름 입력 → 저장 토스트 전 `Ctrl+S` 연타 → upsertMenuMaster 복수 호출.
- **수정**: `saving` state + `savingRef`(동기 재진입 가드) 추가. `submit()` 진입 시 진행 중이면 즉시 return, `Promise.resolve(onSave(...)).finally()`로 해제. 저장 버튼 `disabled={!canSave || saving}` + "저장 중…" 표기.

### BUG-002 — `commitBulkPrice` 반환 타입 불일치 (`lib/cost/bulk-price-update.js`)

- **증상**: 빈 배열 경로는 `0`(숫자), 그 외 경로는 `{ applied, skipped }`(객체)를 반환. 호출자가 숫자로 다루면 객체는 항상 truthy로 평가되어 오작동 가능. (현재 라이브 호출부는 없으나 잠재 결함)
- **수정**: 모든 경로를 `{ applied, skipped }` 객체로 통일하고 JSDoc을 `Promise<{applied, skipped}>`로 정정.

### BUG-003 — 식자재 `baseQuantity`/`priceOverride` NaN 저장 (`lib/ingredient/store.js`)

- **증상**: `Number(patch.baseQuantity)` 변환 시 `Number.isFinite` 검사가 없어 비숫자 문자열(`'abc'`, 잘못 파싱된 import 값)이 `NaN`으로 DB에 영구 저장됨. `calcUnitPrice(price, NaN)`이 null을 반환해 단가 표시가 영구적으로 깨짐. `priceOverride`도 동일.
- **수정**: 두 필드 모두 `Number.isFinite(Number(...)) ? Number(...) : null`로 변환해 유효하지 않은 값은 `null`로 저장.

## Medium

### BUG-004 — `applyDiscount` NaN 전파 (`lib/cost/margin/calc.js`)

- **증상**: `if (!sellingPrice || sellingPrice <= 0) return sellingPrice ?? 0;` — `?? 0`은 `null/undefined`만 대체하고 `NaN`은 통과시켜, `applyDiscount(NaN)`이 `NaN`을 반환 → 마진 테이블 전체 NaN.
- **수정**: `if (!Number.isFinite(sellingPrice) || sellingPrice <= 0) return 0;`. 회귀 테스트 추가(`margin-platform-calc.test.mjs`: NaN/null → 0).

### BUG-005 — `bulkPut` 청크 분할로 원자성 손실 (`lib/db/crud.js`)

- **증상**: 500건 초과 시 청크별 별도 트랜잭션으로 분할해, 중간 청크 실패 시 앞 청크는 롤백되지 않아 부분 적용 상태가 남음.
- **수정**: 청크 분할 제거. 단일 트랜잭션에 모든 put을 큐잉(IDB는 요청 개수 제한 없음, 실패 시 전체 롤백). `onabort` 핸들러 추가.

### BUG-006 — `runTransaction` 예외 무시 (`lib/db/crud.js`)

- **증상**: `work()` 예외 후 `tx.abort()`가 실패하면 onabort가 안 떠서, 큐잉된 요청이 완료되면 `oncomplete`로 `resolve(undefined)`가 되어 work 예외가 묻힘.
- **수정**: `settled` 플래그 도입. `work()`가 throw하면 abort 시도 후 **즉시 reject**하고 이후 콜백을 무시. 모든 경로를 `doResolve`/`doReject`로 단일화.

### BUG-007 — middleware의 `/manifest.json` 미공개 (`middleware.ts`)

- **증상**: `PUBLIC_PATHS`에 `/manifest.json`이 없어 비인증 상태에서 PWA 매니페스트 요청이 `/login`으로 리디렉트 → PWA 설치/매니페스트 파싱 실패.
- **수정**: `PUBLIC_PATHS`에 `/manifest.json` 추가.

### BUG-008 — 전역 단축키가 모달 내부에서 발동 (`hooks/useKeyboardShortcuts.js`)

- **증상**: 단축키 가드가 `INPUT/TEXTAREA/SELECT`만 차단. 모달 내 버튼에 포커스된 상태에서 `n`을 누르면 `/note/write`로 이동해 미저장 폼이 소실. `d`·`g+nav`도 동일.
- **수정**: `active.closest('[role="dialog"], [contenteditable="true"]')`이면 전역 단축키 무시. 더불어 `MenuMasterEditModal`에 `role="dialog"` 부여(BUG-009와 함께).

### BUG-009 — 중첩 모달 Escape 오동작 (`components/menu-master/MenuMasterEditModal.jsx`)

- **증상**: 모달이 `document`에 직접 Escape 리스너를 등록해, 내부 ConfirmDialog가 떠 있어도 Escape 시 외부 모달이 닫힘(동일 target의 stopPropagation은 다른 리스너를 막지 못함).
- **수정**: 모달 카드에 `role="dialog"` + `ref` 부여. Escape 핸들러에서 `[role="dialog"]` 중 **최상위(DOM상 마지막)** 가 자신일 때만 `onClose()` 호출.

### BUG-010 — 노트 편집 페이지 이탈 무경고 (`app/note/[id]/page.jsx`)

- **증상**: 작성 페이지와 달리 편집 페이지는 `setForm`을 직접 넘겨 `isDirty` 추적·`useBeforeUnload`가 없어, 수정 후 탭 닫기/새로고침 시 경고 없이 변경분 소실.
- **수정**: `isDirty` state + `handleFormChange` 래퍼 추가, `useBeforeUnload(isDirty)` 적용. 사용자 편집(`NoteFormBody`)·드래프트 복원만 dirty로 표시, 저장 성공 시 해제(초기 로드 `setForm`은 제외).

### BUG-012 — price-history 정렬 비교자 계약 위반 (`lib/cost/price-history.js`)

- **증상**: `(b.changedAt > a.changedAt ? 1 : -1)` — 동일 타임스탬프에서 -1을 반환해 비교자 모순(엔진별 비결정적 순서).
- **수정**: 3-way 비교 `... ? 1 : ... < ... ? -1 : 0`로 변경(`getHistoryByIngredient`·`getAllHistory`).

### BUG-013 — `toggleDark` stale closure (`components/TopBar.jsx`)

- **증상**: 렌더 클로저의 `dark`를 읽어 빠른 이중 클릭 시 두 클릭이 같은 값을 계산 → 1회만 토글.
- **수정**: `setDark(prev => { const next = !prev; setSetting(...); return next; })` 함수형 업데이트.

### BUG-015 — `confirmDelete` 언마운트 가드 없음 (`hooks/useReportActions.js`)

- **증상**: 360ms 지연·DB 호출 중 언마운트되면 언마운트 컴포넌트에 setState.
- **수정**: `mountedRef` 추가. 지연·DB 호출 후 `mountedRef.current` 확인 후에만 setState/토스트.

### BUG-016 — `editFocusTimerRef` 타이머 미정리 (`hooks/useReportActions.js`)

- **증상**: `startEdit`의 50ms 포커스 타이머가 언마운트 시 정리되지 않아 분리된 DOM에 focus 시도.
- **수정**: cleanup `useEffect`에서 `clearTimeout(editFocusTimerRef.current)`.

### BUG-017 — `useNutritionBaseEditor` 언마운트 가드 없음 (`hooks/useNutritionBaseEditor.js`)

- **증상**: `handleSave`가 DB 쓰기 완료 후 setState/refresh를 호출 — 모달이 먼저 닫히면 언마운트 컴포넌트에 적용.
- **수정**: `mountedRef` 추가, `handleSave`의 후속 setState/showToast/refresh를 가드.

### BUG-018 — `useShipmentReportData` deps 누락 (`hooks/useShipmentReportData.js`)

- **증상**: effect가 `setShipYear/setShipMonth`를 쓰지만 deps에 누락. 현재는 안정 setter라 무해하나, 비안정 setter 전달 시 stale 캡처.
- **수정**: deps에 `setShipYear, setShipMonth` 추가.

### BUG-019 — jette 출고 연도 입력·적용값 불일치 (`app/jette/shipment/page.jsx`)

- **증상**: `normalizePeriodYear`는 클램프 안 함 → 상태/UI엔 `year=1`이 보이지만 `normalizeShipmentPeriod`가 저장 시 2000으로 클램프 → 표시값 ≠ 저장값.
- **수정**: `PeriodInput` onChange에서 `Math.max(MIN, Math.min(MAX, raw))`로 클램프 후 저장.

## 의도적 보류 (코드 변경 없음)

### BUG-011 — `deleteIngredient` cascade 비원자성 (`lib/ingredient/store.js`) · Low

- **현황**: 부모(`cost_ingredients`) 삭제와 알레르기 링크 cascade가 별개 트랜잭션. 단, `nutrition_allergy_links` store는 **v20 마이그레이션에서 제거**되어 `hasStore` 가드로 현재 no-op → 실제 고아 레코드 발생 경로 없음.
- **보류 사유**: 라이브 결함 아님. cascadeErrors 반환 계약을 검증하는 가드 테스트(`ingredient-delete-cascade.test.mjs`)가 있어 임의 삭제 시 회귀 위험.
- **권고**: 향후 새 cascade 대상 추가 시 `lib/db/crud.js`의 `deleteWithChildren`(단일 트랜잭션) 패턴 사용.

### BUG-014 — TopBar 다크모드 아이콘 첫 렌더 플리커 (`components/TopBar.jsx`) · Low

- **현황**: `dark` 초기값 `false` → 마운트 후 effect가 `data-theme`/설정과 동기화하는 과정에서 테마 토글 아이콘이 한 프레임 깜빡일 수 있음.
- **보류 사유**: 현재 패턴은 **하이드레이션 안전**을 위한 의도적 설계(useState 초기화에서 `document` 접근 시 SSR/CSR 불일치 위험). 한 프레임 아이콘 깜빡임보다 하이드레이션 정합성이 우선.
- **권고**: 완전 제거하려면 `<head>` 블로킹 인라인 스크립트에서 아이콘 초기 상태까지 확정해야 하며, 별도 작업으로 검토.
