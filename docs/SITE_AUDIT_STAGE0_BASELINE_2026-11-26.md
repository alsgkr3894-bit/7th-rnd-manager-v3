## 2. 원가 기준값

```bash
npm run baseline:cost -- --check
```

- `-- --check` 없이 실행하면 기준값을 새로 저장한다. 결과는 `.baseline/cost-baseline.json`에 두며 **업무 데이터라 저장소에 올리지 않는다.**
- DB는 읽기 전용으로 읽는다. 기준 단가 파일은 2026-11-23(108행)이다.
- 대표 메뉴 8개(분류·규격별 1개): `P-OR-001-L`, `P-OR-001-R`, `P-ONE-001`, `S-SNK-003`, `S-CHK-002`, `SET-FAM-001-L`, `SET-FAM-001-R`, `T-ETC-001`. 메뉴 95개 전체의 메뉴마스터 원가도 함께 저장한다.
- **수동 원가**는 앱의 원가 함수를 쓰지 않고 원본 단가·포장수량·수량으로 다시 곱한다. 어떤 구성품이 들어가는지(공통 묶음 포함)는 앱의 레시피 행을 따르고, 직접 구성품 수는 저장된 레시피 원본과 대조한다.
- 비교한 값: 수동, 메뉴마스터, 원가마진표, 원가계산 보고서, **실제로 만든 보고서 `.xlsx` 파일의 셀**(메뉴 상세·레시피 출력 시트), PDF 레시피 출력 값.

| 결과 | 내용 |
|---|---|
| 8개 메뉴 | 2원(줄 반올림) 이내로 모두 일치 |
| 반올림 | 단위 단가를 0.1원으로 반올림하는 앱 규칙 때문에 반올림 전 계산과 메뉴당 0~3원 차이 |
| 마진표 | `S-SNK-003`은 세트 전용이라 마진표에 없음(알려진 정상) |
| 저장 직후 재비교 | 다른 항목 0건 |

단가 파일을 새로 올리면 값이 달라지는 것이 정상이다. 코드 변경 전후 비교는 같은 단가 파일 상태에서 해야 한다.

확인하지 않은 것: PDF 파일 자체의 글자, 엑셀 앱에서 여는 확인, 하프앤하프·엣지 결합 메뉴의 수동 계산.

## 3. 성능 기준선

```bash
npm run baseline:perf
```

최신 DB 백업을 임시 DB에 복원하고, 쓰기를 거부하는 프로덕션 서버(Next 16.4.6)를 띄워 새 Chromium에 303,662행을 불러온 뒤 측정한다. 운영 DB에는 쓰지 않는다. 약 10~15분.

측정 PC: i7-12700K, 20스레드, 34GB. 각 값은 3회의 가운데 값이다. "준비"는 화면 제목과 데이터(표 화면은 20행 초과)가 보이는 시점이다.

| 화면 | 새로 열기 | 화면 이동 | 전체 조회(`getAll`) | JS 힙 |
|---|---:|---:|---:|---:|
| 홈 | 689ms | 428ms | 30 / 27회 | 187~190MB |
| 메뉴마스터 | 796ms | 496ms | 33회 | 8 / 140MB |
| 식자재 관리 | 754ms | 497ms | 28회 | 43 / 175MB |
| 원가마진표 | 454ms | 184ms | 20 / 18회 | 6 / 139MB |
| 원가 보고서 | 442ms | (사이드바에 없음) | 19회 | 7MB |
| 노트 목록 | 1,262ms | **964ms** | 16회 | 206~209MB |

| 항목 | 값 |
|---|---|
| 서버에서 불러오기 | 303,662행, 292초 |
| 반복 이동 5바퀴 뒤 홈 힙 | 190 → 189.6 → 189.8 → 189.9 → 190MB (증가 없음) |
| 1초 넘는 `getAll` 경고, 화면 오류 | 0회, 0건 |

문서 15절 목표와 비교: 홈 2초 이내 충족. 방문한 화면 이동 500ms는 노트 목록만 초과(메뉴마스터·식자재 관리는 496~497ms로 경계).

**3단계(속도 개선)의 출발점**

- 한 화면을 여는 동안 같은 저장소를 반복해서 읽는다: 홈 `price_rows` 8회, 메뉴마스터 `menu_master` 5회·`menu_recipes` 4회·`price_rows` 4회, 식자재 관리 `price_rows` 5회.
- 노트·홈에서 힙이 약 190~210MB다. 용량 대부분이 사진인 저장소를 통째로 읽는다.
- 조회 횟수에는 화면이 뜬 뒤 3초 동안의 배지 계산 등이 포함된다.
- 이 PC는 빠른 편이며, 느린 PC의 값은 재지 않았다. 처음 방문(코드 내려받기)은 화면 이동 값에서 뺐다.
