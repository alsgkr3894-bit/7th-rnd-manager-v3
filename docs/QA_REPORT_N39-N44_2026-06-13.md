## 발견 버그 및 수정 (`fix` 커밋 `1b15e5f`)

### Bug 1 — `confirm()` 사용 (정책 위반)

| 항목 | 내용 |
|------|------|
| 위치 | `app/settings/account/page.jsx:539` |
| 문제 | 계정 삭제 시 `if (!confirm(...))` — 코드베이스 전역 `confirm()` 금지 정책 위반 |
| 수정 | `deleteConfirmId` 상태 + `ConfirmDialog` 컴포넌트로 교체. "되돌릴 수 없습니다." 문구 포함 |

### Bug 2 — `useCurrentRole` 계정 전환 후 역할 미갱신

| 항목 | 내용 |
|------|------|
| 위치 | `hooks/useCurrentRole.js`, `lib/auth/accounts.js` |
| 문제 | `useEffect([], [])` — 마운트 1회만 실행. 같은 탭에서 계정 전환해도 `role` 상태가 갱신되지 않아 UI 게이팅이 즉시 반영되지 않음 |
| 수정 | `setActiveAccountId`에 `CustomEvent('rnd:account-changed')` 발화 추가. `useCurrentRole`에서 `storage` 이벤트(타 탭)와 `rnd:account-changed`(같은 탭) 양쪽 리스너 등록 → 계정 전환 즉시 모든 컴포넌트 역할 갱신 |
