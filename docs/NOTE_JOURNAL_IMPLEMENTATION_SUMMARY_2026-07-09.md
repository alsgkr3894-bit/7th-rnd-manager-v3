# 노트목록-연구일지 통합 구현 정리 (2026-07-09)

## 목적

노트목록에 통합된 메뉴개발, 메뉴개선, 샘플테스트, 제품이슈 기록이 연구일지와 PDF 출력에서 같은 기준으로 보이도록 정리했다. 기존 저장 데이터는 이동하거나 삭제하지 않고, 조회/표시/출력 매핑만 보강했다.

## 구현 내용

### 1. 노트목록 기록의 연구일지 연동

- 연구일지 페이지가 기존 메뉴개발 노트 저장소뿐 아니라 샘플/제품이슈 저장소도 함께 읽도록 변경했다.
- 샘플테스트/제품이슈는 노트목록과 같은 통합 레코드 형태로 변환해 날짜별 연구일지 목록, 월별 목록, 기간 PDF에 포함되도록 했다.
- 연구일지에서 통합 샘플 기록을 수정할 때는 일반 노트 상세가 아니라 원본 샘플 상세 화면으로 이동하도록 라우팅을 분리했다.

### 2. 샘플/제품이슈 PDF 출력 라벨 수정

- 샘플테스트/제품이슈 기록이 일반 메뉴개발 노트 라벨로 출력되던 문제를 수정했다.
- 샘플 기록은 작성 폼의 실제 입력 칸에 맞춰 다음 라벨로 출력된다.
  - 테스트 내용 / 조건
  - 샘플명
  - 평가 / 결과
  - 업체명
  - 담당자
  - 단가
  - 개선사항
  - 다음 액션
- 샘플 기록에는 더 이상 `사용 재료`, `상무님 평가` 같은 메뉴개발 전용 라벨을 사용하지 않는다.
- 샘플의 `테스트 내용 / 조건`과 `평가 / 결과`가 한 섹션으로 합쳐지지 않도록 통합 레코드 변환을 분리했다.

### 3. 카테고리/구분 표시 정리

- 샘플 기록의 `category`는 식자재 분류 값이므로 PDF와 연구일지 카드에서 `구분`으로 표시하지 않도록 했다.
- 샘플 기록 메타 정보는 `유형`, `식자재 분류`로 분리해 표시한다.
- 일반 메뉴개발/메뉴개선 노트는 기존처럼 `구분` 표시를 유지한다.

### 4. 연구일지 사진 중복 방지

- 연구일지 작성 폼이 같은 날짜의 샘플/노트 사진을 자동으로 일지 사진에 병합하던 동작을 제거했다.
- 연구일지 저장 시에는 사용자가 일지에 직접 등록한 사진만 저장한다.
- 이미 자동 병합으로 저장된 사진이라도 같은 날짜 원본 샘플/노트에 같은 사진이 있으면 연구일지 카드와 PDF에서 중복 표시되지 않도록 필터링했다.

### 5. 태그/사진 출력 안전성 보강

- 통합 샘플 기록의 태그가 문자열 또는 배열 형태로 들어와도 연구일지 카드와 PDF 출력이 깨지지 않도록 처리했다.
- 연구일지 PDF 출력에서도 사진 로딩 대기와 한글 출력 흐름은 기존 방식을 유지했다.

## 데이터 보존 메모

- 기존 노트, 샘플, 제품이슈, 연구일지 데이터는 삭제하거나 마이그레이션하지 않았다.
- 샘플 사진과 연구일지 사진의 중복 문제는 저장 데이터를 강제로 지우지 않고 출력/표시 단계에서 중복을 제외하도록 처리했다.
- 사용자가 연구일지 사진을 삭제하고 저장하면 이후 자동으로 다시 붙지 않는다.
